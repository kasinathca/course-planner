# FFCS Studio — Codex working agreement (local-browser edition, v0.2)

Read `docs/00_START_HERE.md`, `docs/10_IMPLEMENTATION.md`, `docs/12_PHASES_AND_CODEX.md`, and `docs/16_LOCALHOST_RUNTIME_AND_SECURITY.md` before writing code; then read all remaining documents, schemas and sanitized examples. User's final interface decision overrides older wording: **a local website at `http://127.0.0.1:8765`**, NOT PySide6, Qt, native desktop, Electron, Node, or a public/cloud website.

**Approved implementation**: Python 3.12+ with FastAPI and Uvicorn for a local HTTP server; SQLite; plain HTML, CSS and modern vanilla JavaScript ES modules served as static files, with no Node, npm, build tooling, CDN or remote runtime requests. Jinja2 server-rendered HTML is permitted. The local API is allowed; *external* APIs and hosted services are prohibited. Python packages may need to be installed once while online; subsequent operation must be offline. Windows 11 is the initial target.

Core rules: no invented faculty, section pairing or official time mapping; retain every raw source row; unknown slots fail strict planning. Keep domain/solver independent of HTTP/UI and write pure Python tests. VTOP collection is a separate safe Tampermonkey userscript that captures only displayed course/category/table data after user selection and exports files; no portal automation, credential scraping, or registration automation. Do not commit private portal HTML, auth tokens, `node_modules`, `.next`, or student's identifying data. Start Phase 0 only, validate and report actual tests, and do not push GitHub without express approval.
